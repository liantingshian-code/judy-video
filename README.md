# 追劇雷達

輸入一部劇的名字 → 一頁生成 **Threads / 抖音 / Instagram / YouTube** 的搜尋連結，連中文名、英文名、韓文名、相關劇推薦都幫你抓好，不用每個 App 重打一次。

**不用先選這是韓劇還是陸劇**，也不用挑類型。打劇名就好。

目標很單純：**減少滑手機的時間**。

---

## 它在做什麼

| 功能 | 說明 |
|---|---|
| 打劇名出連結 | 內建 56 部劇（36 韓劇、20 陸劇）字典，中文／英文／韓文任一種打進去都認得 |
| **打演員也行** | 字典認不出來的名字會自動去問**維基百科**，列出這個人演過的電視劇；點一部就變成主搜尋 |
| 自動補別名 | 認得就自動填英文名，`淚之女王` → `Queen of Tears`；IG 標籤頁自動變成 `/explore/tags/queenoftears/` |
| 相關劇推薦 | 每部戲給 3 部同類型／同片源／同國別的，附推薦理由，一鍵接著看 |
| 進階詞晶片 | 「名場面」「結局」「反轉」「高能片段」…點一下加進關鍵字，搜尋範圍立刻收窄 |
| 免雷模式 | 一鍵加上韓文 `무스포` 或中文 `无剧透`（跟著劇的國別自動選），追劇中的人真的會需要 |
| 最近搜過 | 最多 8 筆，存在瀏覽器裡，下次直接點回去，不用重打 |
| 深／淺色 | 右上角切換，手機晚上不刺眼 |
| 加到手機主畫面 | 附 manifest，手機瀏覽器「加入主畫面」後像 App 一樣開 |

**沒有的東西**：沒有帳號、沒有追蹤清單、沒有片段庫、沒有匯出／匯入、沒有付費牆、沒有 API 金鑰。

## 打演員名字也可以

這是給「只記得演員、不記得劇名」的時候用的。

打一個字典裡沒有的名字（例如 `李英愛`、`宋慧喬`、`Lee Young-ae`），停頓一下，頁面會自己去問維基百科「這個人演過什麼電視劇」，然後列成可以點的清單：

- 點一部戲 → 它就變成主搜尋，英文名、IG 標籤連結、相關劇推薦全部照常運作
- 點「只想搜演員本人」→ 直接用演員名字當關鍵字去四個來源找片段
- 字典有收的戲會排在前面（因為那些查得到比較多東西）

資料來源是 **Wikipedia 與 Wikidata 的公開 API**（免金鑰、CORS 開放）：先在維基百科找「這個人」的條目（中文維基與英文維基都會試，所以 `李英愛` 和 `Lee Young-ae` 都能查到同一位），再用 **Wikidata** 取這個人的演出作品，而且只抓「電視連續劇」類型，避免把電影和 MV 混進來。中文名、英文名、羅馬拼音名都能查。

需要網路。查不到或沒網路時，頁面會老實說一聲，不會假裝成功——你還是可以直接用輸入框裡的字去搜。

## 為什麼是「點出去搜尋」而不是直接抓貼文列表？

Threads、抖音、Instagram **都沒有開放「依關鍵字搜尋貼文」的公開 API**。
Threads 雖然有官方 Keyword Search API，但需要 app 審核加 `threads_keyword_search` 權限；抖音與 IG 連申請都沒有。

所以這個工具的作法是：**不爬蟲、不繞過任何限制**，直接把你送到該平台**真正的搜尋結果頁**。結果是平台自己給的。

優點：不用帳號、不碰反爬、不會被封號、零金鑰、零後端、離線也能開。
缺點：點出去那一下仍需要你自己是登入狀態；預設排序由平台決定（Threads 搜尋結果有 **Recent** 分頁可切最新）。

## 隱私

最近搜過的紀錄**只存在你自己的瀏覽器 localStorage**，沒有帳號、不上傳任何伺服器、沒有追蹤碼。

查維基百科時，**只有你打的那個名字**會送到 Wikimedia 的公開 API，跟一般網頁載入沒有差別。這份演員片單**不會**被存進瀏覽器，關掉分頁就沒了。

## 本機開啟

直接用瀏覽器打開 `index.html` 即可，不需要安裝任何東西（沒有 npm、沒有建置步驟）。

## 部署到 GitHub Pages

在這個資料夾開一個終端機：

```bash
git init
git add .
git commit -m "feat: 追劇雷達 — 打劇名一頁串聯 Threads/抖音/IG/YouTube 搜尋"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<倉庫名>.git
git push -u origin main
```

接著在 GitHub 倉庫頁面：

**Settings → Pages → Build and deployment → Source 選 `Deploy from a branch` → Branch 選 `main` / 資料夾選 `/ (root)` → Save**

等 1～2 分鐘，網址會是 `https://<你的帳號>.github.io/<倉庫名>/`。

手機上開那個網址 → 瀏覽器選「加入主畫面」，就有獨立 App 圖示了。

## 字典要怎麼加劇？

打開 `index.html`，搜尋 `RAW_KR` 或 `RAW_CN`，照那個格式加一行就好：

```js
['中文劇名', 'English Name', '한국어 이름', '類型|類型', '年份', '片源'],
```

`RAW_KR` = 韓劇，`RAW_CN` = 陸劇。加完存檔，直接重新整理就生效，不用重新部署流程。

## 瀏覽器需求

Chrome / Edge / Safari 近期版本。用到 `localStorage`、`color-mix()`、`backdrop-filter`。
